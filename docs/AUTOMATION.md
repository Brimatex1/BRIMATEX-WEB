# الأتمتة على المضيف

مهمّتان مجدولتان على حساب cPanel، وكل ما تحتاجه عنهما.

## ١. النشر التلقائي — كل 5 دقائق

```
*/5 * * * *  /bin/bash /home4/brimatex/brimatex-git/scripts/auto-deploy.sh >/dev/null 2>&1
```

يسحب المضيف من GitHub بنفسه عبر https (المستودع عامّ، فلا مفتاح ولا رمز
في أي مكان) وينشر بـ`scripts/deploy.sh` — نفس ما يشغّله `.cpanel.yml`.

- **لا جديد** → خروجٌ صامت بلا سطر سجلّ.
- **الواجهة تغيّرت ولم يُودَع ناتج بنائها** → ينتظر وركفلو GitHub حتى 20
  دقيقة، ثم ينشر (تعديلٌ لا يغيّر الناتج لا يُنتج التزام بناء أصلاً).
- **تغييرٌ محلي في نسخة المضيف** → يتوقّف ويُسجّل. لا `reset` ولا `force`.
- **فشل** → إعادة المحاولة بعد ساعة، لا كل خمس دقائق.

**السجلّ:** `~/logs/brimatex-auto-deploy.log` · **إيقاف مؤقّت:** أنشئ
`~/.brimatex-auto-deploy-off` · **إزالة:** احذف المهمّة من Cron Jobs.

> **درسٌ مدفوع الثمن:** نسخة cPanel من المستودع بلا `remote.origin.fetch`،
> فـ`git fetch origin main` لا يُحدّث `refs/remotes/origin/main`. أول نسخة
> من السكربت كانت تقارن الرأس بمرجعٍ قديم فترى «لا جديد» أبداً وتخرج
> صامتة. السحب الآن بـrefspec صريح. إن بدا أن المهمّة لا تفعل شيئاً، فأول
> ما يُفحَص هو `git rev-parse origin/main` في `~/brimatex-git`.

## ٢. مزامنة حالات الطلبات والإشعارات — كل 10 دقائق

```
*/10 * * * *  /bin/bash /home4/brimatex/app/scripts/cron-order-sync.sh >> /home4/brimatex/logs/brimatex-order-sync.log 2>&1
```

الفريق يعمل في أودو: تأكيد الفاتورة وتسجيل الدفع يحدثان هناك، فلا يعلم
المتجر ولا يصل العميل إشعار. هذه المهمّة تقرأ فواتير الطلبات غير المنتهية
من أودو، تُحدّث السجلّ، وتُرسل إشعار Expo لما تبدّل (`src/lib/orderSync.js`).

- الإشعار مرّة واحدة لكل انتقال: التشغيل التالي يرى الحالة نفسها فيصمت.
- عطبٌ في طلب (فاتورة محذوفة، انقطاع شبكة) لا يوقف الباقي.
- **مطابقة المخزن:** التطبيق يعمل تحت Passenger ببيئته، وcron يقرأ `.env` —
  فالغلاف يسأل `/api/health` عن حقل `store` ويطابقه، وإلا قرأت المزامنة
  قاعدةً غير التي يكتب فيها الموقع.
- قراءةٌ فقط للتجربة: `DRY_RUN=1 bash scripts/cron-order-sync.sh`

**السجلّ:** `~/logs/brimatex-order-sync.log`

> **ما زال ناقصاً:** التسليم إلى الآيفون ينتظر حساب Apple — رمز الإشعار لا
> يُصدر إلا لنسخةٍ مبنيّة بمفاتيح APNs، وExpo Go لا يُصدره. الخادم جاهز،
> فأوّل نسخة TestFlight تبدأ الإشعارات بلا عمل إضافي.
