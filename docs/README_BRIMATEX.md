# BRIMATEX - متجر المراتب والإسفنج 🛏️

متجر إلكتروني عربي RTL شامل لبيع المراتب والإسفنج الليبي.

## الميزات ✨

- ✅ واجهة عربية RTL كاملة
- ✅ نظام مصادقة برقم الهاتف
- ✅ سلة تسوق مع localStorage
- ✅ بحث عن المنتجات مع حفظ التاريخ
- ✅ عرض تفاصيل المنتجات الكاملة
- ✅ ألوان بريماتكس الرسمية
- ✅ دعم اللغة العربية الكاملة
- ✅ عملة بالدينار الليبي (د.ل)

## البدء السريع 🚀

```bash
# 1. تشغيل السيرفر
node server.js

# 2. فتح المتصفح
http://localhost:3000
```

## الملفات الرئيسية 📁

- `server.js` - خادم Node.js
- `public/index.html` - الواجهة الأساسية
- `public/app.js` - منطق الجانب الأمامي
- `public/styles.css` - التصميم والألوان
- `lib/auth.js` - نظام المصادقة
- `data/` - قاعدة البيانات المحلية (JSONL)

## التقنيات المستخدمة 🛠️

- Node.js (خادم بدون تبعيات)
- HTML5 + CSS3
- JavaScript (ES6+)
- localStorage
- SHA-256 للتشفير
